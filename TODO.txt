	•	Tests written & passing:
	•	Unit tests for mapping raw HID info → stable ID
	•	Fallback behavior if device has limited identifying info

Issue 2.2 – Core scroll event handling engine
	•	Implement event tap / event handler for scroll wheel events
	•	Map incoming events to originating device
